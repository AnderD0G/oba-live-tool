# 电脑助播台自由发言

在电脑「实时助播台」展开「自由发言」。这个入口用于主播自己向公屏发言，不需要选择观众、关联评论或开启真实采集。手机助播台没有自由发言入口。

## 使用流程

1. 先在电脑登录平台账号并选择真实直播间，确认面板显示的「当前直播间：@账号」。可以是自己的直播间，也可以是已经选择的其他直播间。
2. 在「自由发言中文草稿」输入内容，或点击「语音输入」。语音使用服务电脑的麦克风，点击「结束并填入草稿」后才取得识别文字；录音期间如果改过草稿，识别结果会单独保留，可选择追加。语音只填写中文草稿。
3. 「发言语言」默认是「保持原文」。需要翻译时选择目标语言，再点击「翻译并预览」，等待结果后核对「自由发言发送预览」；译文可以编辑。修改中文或目标语言会清除旧译文，需要重新翻译或填写预览。
4. 等待草稿保存完成，核对直播间和发送预览，然后主动点击「发送到当前直播间」。翻译、语音识别、刷新和打开面板都不会代替这个发送步骤。
5. 发送后到直播间公屏核对。继续发言时点击「为当前直播间新建草稿」。

翻译使用当前配置的模型服务，遵守 AI 暂停状态和请求额度。不需要翻译时保留原文即可。

## 房间变化与结果核对

草稿绑定创建时的真实浏览器会话与直播间。直播间或登录会话变化后，原稿保留，发送会被阻止；先核对实际房间，再点击「为当前直播间新建草稿」。新草稿不会继承上一份草稿的文字。

「发送结果待确认」可能发生在提交后连接中断等情况下。应用不会自动重发，原草稿保持锁定；先在公屏确认是否出现，再决定下一步。平台页面接受单次提交的提示不替代公屏核对。

自由发言草稿只保存在应用内存中，退出应用后清除；不会为这段文字创建假观众、假评论或采集记录。关闭应用会取消待处理的翻译和发送任务。
