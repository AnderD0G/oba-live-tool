# 桌面模拟实验室

以下是集成模拟实验室的桌面版本（voice.60）的使用流程；实际安装版本以应用显示为准。

1. 在电脑助播台展开「模拟数据实验室」，先导出当前元数据和示例 JSON。给生成数据的 Worker 元数据，让它按当前观众规则创建用户等级、人工地区标签和相应语言的评论。
2. 把生成的 JSON 拖入面板，或开启 Worker API 后由本地/局域网 Worker 上传。默认端口为 `18767`；实际地址与独立临时密钥以面板为准。在线总览为 `/mock/docs`，机器契约为 `/mock/openapi.json`。密钥通过 `Authorization: Bearer ...` 请求头传递。
3. 准备成功只暂存在内存。先停止真实采集，再点「开始模拟」。手机打开普通手机助播台入口，即可查看同一模拟现场和处理消息；手机没有导入、播放或清空入口。
4. 模拟使用正常分类、翻译和草稿流程，沿用启动时复制的助播设置。可以在模拟状态下修改观众规则、回复规则和本地特效开关，这些修改只在本次内存实例中生效。自动回复模式也只生成待确认草稿。模型调用仍使用已配置的供应商和请求额度。
5. 要测试实际回复，仍在电脑登录并选择真实直播间，核对两端显示的真实发送目标，再在具体草稿上手动发送。自己的直播间和其他直播间都可以。Worker 密钥不能公开发送，也不能开始模拟。
6. 「停止模拟」保留当前内存历史，可在历史查询中复盘；「清空模拟数据」销毁这批用户、事件、草稿和历史；「退出模拟」清除并返回真实助播台。退出应用也会丢失模拟数据。OBS 录像文件由你主动录制，按 OBS 的录像目录保留。

元数据反映当前模拟实例的有效观众规则；尚未创建实例时读取真实已保存规则。修改规则后应重新获取元数据并生成批次，过期版本会被拒绝。清空或退出后可重新从真实设置建立实例。

模拟数据不进入正式 SQLite、JSONL、观众档案或互动审计。内存事实日志上限为单实例 100000 条内部记录、64MiB，达到上限会提示清空，不会转存磁盘。单批 JSON 最大 2MiB、1000 用户、5000 事件、30 分钟。

`manualCountry` 表示模拟的人工地区标签；评论语言由正常翻译流程检测。两者都不代表平台验证的国籍、IP 或真实位置。上传不能预填译文、分层结果或已发送状态来绕过处理流程。

开始模拟前可勾选「模拟时播放 OBS 本地特效」（默认勾选），仅设置模拟实例的本地特效开关。已有钩子和效果组按当前配置运行；真实钩子为空时，提供仅在内存中的欢迎、点赞、关注测试模板，直接使用本次导入的原生来源。欢迎样式可在模拟观众规则的「欢迎特效」中选择绿幕视频或 HTML 样式。不会给真实钩子添加规则。停止或清空会取消本次延迟动作、清理播放并尝试恢复临时文字来源；OBS断线或崩溃时须人工核对其当前画面。
