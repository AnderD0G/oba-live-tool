# Mac 直播麦克风热键

OBA 助播台里的“切换 TK Studio 麦克风”按钮调用 TikTok LIVE Studio 自带的输入设备静音切换热键。主播麦克风可以同时作为 TK Studio 的直播输入和豆包的语音识别输入；按钮只改变 TK Studio 的收音，不禁用物理设备，不改变系统默认麦克风，不依赖 OBS 或虚拟声卡。

## 设置与使用

1. 在 TK Studio → Settings → Hotkeys 开启 Use hotkeys。
2. 将 Audio → Mute / Unmute input device 设置为 **Control + Option + M**。编辑完按 Tab 提交，再离开页面后返回核对。不要绑定到 output device。
3. 在 OBA 助播台点击“授权热键控制”，按 macOS 的提示允许控制，再点“检查连接”。
4. 首次集中验收热键能正确切换，然后把 TK Studio 恢复为正常开麦；后续以此作为联动起始状态。
5. 桌面或手机点击“使用电脑麦克风”，OBA 先发一次热键切断直播人声，再开始豆包识别；成功结束或取消录音后再发一次，恢复直播人声。识别文字只填入中文草稿，翻译和发送由你主动操作。

这是切换热键：若麦克风已静音，再点一次会开麦。界面根据已发送的动作维护“直播 / 豆包”的预期路由，不伪装成读取了真实静音状态；首次验收后无需逐次确认，也不依赖 CUA 或 REA 实时识别界面。原生辅助程序只支持固定组合和固定应用，必要时短暂激活 TK Studio。桌面、手机共用一个录音 owner 与热键串行边界，录音期间不能单独切换。

备用“切换直播麦克风”用于手动操作和调试，会改变联动基准。若手动修改 TK Studio 麦克风，或热键超时、恢复失败，请先手动恢复 TK 开麦，再点击一次“我已恢复 TK 开麦，重新对齐”；对齐不发热键，活动录音期间不可执行。结果未知的切换不会自动重试。豆包识别已成功但恢复热键失败时，识别文字仍保留，并单独提示恢复开麦。

首次开播验收还应确认观众没有通过摄像头麦克风或其他音频来源听到中文。OBS 可以只负责画面；该联动不会改系统默认麦克风或关闭物理设备。手机控制不依赖正在采集评论，机位和麦克风控制仅在本次手机入口有效期间可用。

## 构建

使用 `pnpm build:mac` 会编译并打包 macOS 原生热键辅助程序。该功能只在 Mac 提供，Windows 构建配置不增加 Mac 二进制依赖。用户设备、热键偏好和授权状态均保留在本机，不提交到仓库。
