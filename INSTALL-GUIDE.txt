OBA 弹幕与打印 — Windows 安装说明

1.6.3-codex.11：新增 TikTok LIVE 第一版测试，支持应用内登录、实时新弹幕、弹幕捕手、打印及回复入口。
更新前退出旧版，在相同目录安装新版。连接抖店时选择“抖音小店”，然后按页面提示登录。
连接回归使用离线模拟页面验证，真实账号的连接结果需安装后确认。

支持 Windows 10 / 11 x64。双击安装程序，选择安装目录即可。
安装包内置 Electron 和官方 Codex CLI 0.154.0，不需要安装 Node.js、Python 或开发环境。
预留至少 2 GB 磁盘空间用于安装和临时解压。本版不包含语音服务、声音样本或模型。

首次启动：
1. 在“安装与环境检查”查看浏览器、Codex 登录及打印机。
2. 检测到 Edge / Chrome 时自动配置当前账号的空白浏览器路径。
3. AI 规则助手和文字回复需要可用的 Codex 账号。点击“登录 ChatGPT”，在浏览器完成后重新检测。
   已安装且兼容的 CLI 会复用；没有时自动使用内置组件。不会安装全局 npm 包。
   检测登录不代表网络、订阅额度已验证。已有固定规则的匹配和打印不调用 AI。
4. 小红书：在中控台选择小红书，登录新电脑的千帆账号，连接后开始监听。
   TikTok：选择 TikTok LIVE，填写正在直播的主播 @账号，连接后在打开的网页完成登录，再开始监听。
   TikTok 不回放连接前的历史弹幕。第一版发送回复依赖 TikTok 网页评论输入框，页面改版时请查看日志。
5. 在弹幕捕手中制定并确认规则，再开启捕获。新电脑不会携带旧电脑的规则和历史数据。
6. 接上打印机，安装厂商驱动。在扣号打印选择实际打印机和 40 × 30 mm 标签。
   先预览，再手动打印一张确认纸张方向、字体和驱动纸张尺寸，最后按需开启自动打印。

数据与重启：
捕获记录和队列保存在当前 Windows 用户的应用数据目录，不在安装包内。
卸载默认保留应用数据。每次启动后捕获和自动打印均需自行开启，避免误发单。
本版禁止自动升级为上游版本，以免覆盖定制功能。更新请安装后续定制安装包。
TikTok 弹幕接收使用第三方 AGPL 组件，详情见安装目录 THIRD-PARTY-NOTICES.txt。

常见问题：
没有浏览器：在检查页点击“安装 Edge”，完成官方安装后重新检测。
没有打印机：点击“添加 / 管理打印机”，安装对应型号驱动。Microsoft Print to PDF 不是实体标签机。
AI 不可用：确认登录、网络和账号额度；固定筛选和打印仍可以使用。
找不到原电脑的队列：这是新电脑的独立数据，安装包不会复制账号、弹幕或打印记录。

本安装包尚未购买 Windows 代码签名证书，Windows 可能显示发布者未知。
仅从你自己保存的可信安装文件安装，不要关闭系统防护。
